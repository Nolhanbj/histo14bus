# Guide Complet : Publier le site en ligne & le Référencer sur Google (SEO) 🚀

Ce guide vous explique pas à pas comment mettre votre site **Histo14Bus** en ligne gratuitement avec une adresse sécurisée (HTTPS) et comment faire pour qu'il apparaisse en premier sur Google.

---

## PARTIE 1 : Publier votre site en ligne (100% Gratuit)

Vous avez 3 excellentes options gratuites. La **Méthode 1 (Vercel ou Netlify)** est la plus simple et rapide (moins de 2 minutes).

### Méthode 1 : Netlify Drop (En 30 secondes, sans rien installer) ⭐ Recommandé pour débuter
1. Rendez-vous sur [app.netlify.com/drop](https://app.netlify.com/drop) (créez un compte gratuit si besoin).
2. **Glissez-déposez** simplement l'ensemble de votre dossier `site wixe` dans le rectangle sur la page.
3. Netlify génère instantanément votre site en ligne (ex: `https://histo14bus.netlify.app`).
4. Dans **Site settings > Domain management**, vous pouvez renommer l'adresse gratuitement en `https://histo14bus.netlify.app` ou y lier votre propre nom de domaine.

---

### Méthode 2 : Vercel (Ultra performant et moderne)
1. Créez un compte gratuit sur [vercel.com](https://vercel.com).
2. Cliquez sur **Add New > Project** et importez votre dossier ou votre dépôt GitHub.
3. Cliquez sur **Deploy**. Votre site est en ligne avec certificat SSL / HTTPS gratuit.

---

### Méthode 3 : GitHub Pages
1. Créez un dépôt public sur GitHub (ex: `histo14bus`).
2. Déposez-y tous les fichiers de votre dossier `site wixe`.
3. Allez dans **Settings > Pages** de votre dépôt GitHub.
4. Sous **Build and deployment**, choisissez la branche `main` et le dossier `/ (root)` puis cliquez sur **Save**.
5. Votre site sera disponible à l'adresse : `https://votre-pseudo.github.io/histo14bus/`.

---

## PARTIE 2 : Référencer votre site sur Google (Google SEO) 🔍

J'ai déjà préparé et intégré dans votre code :
- Le fichier [`sitemap.xml`](sitemap.xml) (plan du site complet pour les robots Google).
- Le fichier [`robots.txt`](robots.txt) (autorisations pour les moteurs de recherche).
- Les balises **Open Graph** (titre, description et aperçu image pour les partages WhatsApp, Facebook, X/Twitter).
- Les données structurées **Schema.org** (balises pour que Google comprenne qu'il s'agit d'un portail sur les bus/tramways de Normandie).

### Étapes à suivre une fois votre site publié :

### 1. Inscrire votre site sur **Google Search Console**
1. Rendez-vous sur [search.google.com/search-console](https://search.google.com/search-console).
2. Connectez-vous avec votre compte Google.
3. Cliquez sur **Ajouter une propriété** et entrez l'adresse de votre site (ex: `https://histo14bus.netlify.app` ou votre nom de domaine).
4. Validez la propriété (via balise HTML ou DNS selon les instructions fournies).

### 2. Envoyer votre Plan de site (`sitemap.xml`) à Google
1. Dans le menu de gauche de Google Search Console, cliquez sur **Sitemaps**.
2. Dans le champ *"Ajouter un sitemap"*, saisissez : `sitemap.xml`
3. Cliquez sur **Envoyer**. Google va crawler et indexer immédiatement toutes les pages, photos et sections de votre site !

### 3. Demander l'indexation prioritaire de la page d'accueil
1. Dans la barre de recherche tout en haut de Google Search Console (*"Inspecter une URL"*), collez l'URL de votre site.
2. Cliquez sur **Demander une indexation**.
